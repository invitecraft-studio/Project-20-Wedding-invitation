# Temple Wedding Invitation (React + Vite)

Edit names, dates, venue, WhatsApp number in `src/data.js`.

## Run
    npm install
    npm run dev

## Deploy (GitHub + Vercel)
    git init && git add . && git commit -m "wedding invitation"
    git branch -M main
    git remote add origin https://github.com/<you>/<repo>.git
    git push -u origin main
Then on vercel.com: Add New > Project > import the repo > Deploy (Vite is auto-detected).
